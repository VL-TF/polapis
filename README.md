# Vieta be patyčių – Patikimo pranešėjo paslauga

Trusted Flagger landing page iteration v2.

## Project Structure

- `index.html` – Main HTML file with all sections
- `styles.css` – CSS styling following vaikulinija.lt design principles
- `script.js` – JavaScript for smooth scrolling and basic interactivity

## Page Structure

1. **Hero Section** – Main headline with three action buttons
2. **Apie paslaugą** – Brief service description with illustration placeholder
3. **Kaip tai veikia** – 4-step process explanation
4. **Emoji Test Placeholder** – Interactive quiz placeholder (Coming soon)
5. **Reporting Categories** – 8 category cards with icons
6. **Yes/No Quiz Placeholder** – Decision quiz placeholder (Coming soon)
7. **Status Lookup** – Report status check form
8. **Platform Section** – Partner platforms information
9. **FAQ** – Frequently asked questions
10. **Partners** – Partner logos
11. **Footer** – Copyright information

## Key Features

- **Three primary action buttons** in hero section:
  - 🟠 Pranešti apie turinį (links to form)
  - 🔵 Ką galima pranešti (smooth scroll to categories)
  - ⚪ Patikrinti pateikto atvejo būseną (smooth scroll to status)

- **Reduced text** – Concise, scannable content
- **Interactive placeholders** – Ready for future implementation
- **Responsive design** – Mobile-first approach
- **Visual identity** – Calm, friendly, empowering design suitable for all ages

## Design Principles

- Calm and friendly aesthetic
- Easy to understand for children, teenagers, and adults
- Uses illustrations, icons, cards, and white space
- Each section answers one question only
- Follows vaikulinija.lt visual identity

## Customization

### Illustrations
Replace `.illustration-placeholder` divs with actual illustration images.

### Platform Logos
Replace `.placeholder-logo` divs with actual platform logo images.

### Interactive Features
The emoji test and yes/no quiz are placeholders marked with "Coming soon" badges. These can be implemented when ready.
